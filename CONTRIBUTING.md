# Contributing to SerakDepMS Studios DevKit

Thank you for considering contributing!

By participating, you agree to uphold our [Code of Conduct](./CODE_OF_CONDUCT.md).

---

## How to Contribute

1. **Fork** the repository.

2. **Clone** your fork:
```bash
git clone https://github.com/YOUR_USERNAME/serakdepms-devkit.git
cd serakdepms-devkit
```

3. **Create a branch** with a descriptive name:
```bash
git checkout -b feature/my-tool
git checkout -b fix/my-bugfix
git checkout -b docs/update-readme
```

4. **Add your contribution** in the appropriate division folder. Include a `README.md` explaining what your tool does.

5. **Commit** using conventional commits:
```bash
git commit -m "feat(python-data-science): add CSV parser utility"
git commit -m "fix(backend-apis): resolve JWT expiry bug"
git commit -m "docs(web-development): update README"
```

**Commit types:**
- `feat` — New feature or tool
- `fix` — Bug fix
- `docs` — Documentation
- `refactor` — Code refactor
- `test` — Tests
- `chore` — Maintenance

6. **Push** and open a **Pull Request**:
```bash
git push origin feature/my-tool
```

## What We Accept

| Accepted | Not Accepted |
|---|---|
| Utility scripts | Malware |
| Libraries | Exploits |
| Boilerplates | NSFW content |
| Algorithms | Copyrighted code |
| Documentation | Spam |
| Config templates | Unrelated content |

---

## Style Guidelines

- **Code:** clean, readable, well-commented.
- **File names:** `kebab-case`.
- **Documentation:** include a short `README.md` per tool.
- **Tests:** add them when possible.
