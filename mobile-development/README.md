# Mobile Development Division

Welcome to the **Mobile Development** division of SerakDepMS DevKit.

## What goes here

- Flutter widgets and packages
- React Native components
- Android (Kotlin/Java) utilities
- iOS (Swift) snippets
- Mobile UI templates
- Push notification handlers
- App boilerplates

## How to add your tool

1. Create a folder with the name of your tool (e.g., `flutter-custom-button/`).
2. Inside, add:
   - `README.md` explaining what it does
   - The source file(s)
   - Dependencies (if applicable)
   - Screenshots (if applicable)
