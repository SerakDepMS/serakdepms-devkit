# Python & Data Science Division

Welcome to the **Python & Data Science** division of SerakDepMS DevKit.

## What goes here

- Data analysis scripts (pandas, numpy)
- Automation tools
- Machine Learning utilities (scikit-learn, PyTorch)
- Web scrapers (BeautifulSoup, Scrapy)
- Scientific computing
- CLI tools
- API clients

## Structure
python-data-science/
├── README.md
├── tool-name/
│ ├── README.md
│ ├── tool.py
│ ├── requirements.txt
│ └── tests/
└── ...


## How to add your tool

1. Create a folder with the name of your tool (e.g., `csv-parser/`).
2. Inside, add:
   - `README.md` explaining what it does
   - The `.py` file(s)
   - `requirements.txt` for dependencies
   - Tests (if applicable)
