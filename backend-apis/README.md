# Backend & APIs Division

Welcome to the **Backend & APIs** division of SerakDepMS DevKit.

## What goes here

- REST API boilerplates
- GraphQL schemas
- gRPC services
- Authentication systems
- Database connectors
- Microservice templates
- Docker configurations
- Message queue utilities

## Structure
backend-apis/
├── README.md
├── my-api-template/
│ ├── README.md
│ ├── src/
│ ├── package.json
│ └── .env.example
└── ...


## How to add your tool

1. Create a folder with the name of your tool (e.g., `jwt-auth-template/`).
2. Inside, add:
   - `README.md` explaining what it does
   - The source file(s)
   - Configuration examples (`.env.example`)
   - Tests (if applicable)
