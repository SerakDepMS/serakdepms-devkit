## How to add your tool

1. Create a folder with the name of your tool (e.g., `unity-inventory-system/`).
2. Inside, add:
   - `README.md` explaining what it does
   - The source file(s)
   - Instructions for integration
   - Screenshots or GIFs (if applicable)
